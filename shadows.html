Shadows

Paper account: no real money Test copy, not the live file

A shadow is a job that runs on its own each weekday and records what it sees. It does not decide a trade on its own. This page shows each shadow, when it last recorded and when it can first show a result.

The shadows

    How to read the status

    Running
    It recorded on the last weekday that it had to.
    Late: missed a weekday
    A weekday has no record, and its run time passed more than 90 minutes ago.
    Waiting for data
    It ran, but its last run recorded nothing to use.
    Not run yet
    It has no record yet.
    Unknown
    Its record could not be read.

    Only trading days count. A weekend or a market holiday is never late. All times are Central time.

    A due date marked "about" is a projection from the days recorded so far. It moves if a shadow misses a day.

    Counts and dates come from each shadow's own record on the Pi. This page shows no stock names and no model text. Nothing on this page trades.
